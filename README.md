# Duplex Align

A free browser tool for designing double-sided prints. Design the front and back of a sheet, align them with a live mirrored guide, and print duplex without the trial and error.

- **Landing page** — `/index.html`
- **App** — `/app/index.html`

## Development

```
npm install
npm run dev
```

## Build

```
npm run build
npm run preview
```

Outputs a static site to `dist/` — the landing page at `/` and the app at `/app/`.
